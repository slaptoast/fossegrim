Vendored, unmodified builds of Butterchurn, the WebGL 2 port of the MilkDrop
visualizer, and its default preset pack. Loaded on demand by js/visualizer.js.

Source: https://github.com/jberg/butterchurn and
https://github.com/jberg/butterchurn-presets (npm tarballs). To update,
replace these files from the matching versions' `lib/` folders.
